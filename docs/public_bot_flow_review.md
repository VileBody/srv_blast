## 1. Форматы субтитров

### Паблик-бот (5 кнопок):

| Кнопка | Код | Описание |
|--------|-----|---------|
| «Impulse» | `impulse_2nd` | Динамичные субтитры слово за словом с акцентами |

| «Trendy» | `trendy_5th` | Одно слово по центру (5th template) |

Те же 5 + «Обычные blocks» (`legacy_blocks`) + «Scenes 3rd Single-Step» (`scenes_3rd_single`).

## 2. Вход — /start и подписка

### Что происходит

1. `/start` → проверка состояния.
2. Если `SEASON_FLOW_ENABLED=1` и новый пользователь → сезонный онбординг.
3. Иначе → `_move_to_wait_audio`.
4. Начальные кредиты выдаются **только после подписки** на канал (не на `/start`).

### Сообщения

```
WAIT_SUBSCRIPTION:
Привет! Подпишись на наш канал, чтобы начать.
[Подписался!]

После подтверждения → WAIT_AUDIO:
Привет. Отправь трек аудио-файлом, и я соберу клип.

Доступно генераций: N
[Отправить трек]
```

Если есть сохранённый трек — добавляется `[Сделать под тот же трек]`.

## 3. WAIT_AUDIO — загрузка трека

### Путь: новый трек

1. Получает audio file_id.
2. `"Скачиваю файл и готовлю mp3…"`
3. Конвертация ffmpeg, валидация размера.
4. Сброс полей предыдущей сессии (lyrics, footage, timing, batch, jobs и т.д.).
5. → `STAGE_WAIT_LYRICS_TEXT`.

```
Трек готов! Пришли текст песни обычным сообщением.
Он нужен для точной синхронизации субтитров с аудио.
```

### Путь: REUSE_INPUT — «Сделать под тот же трек»

- Проверяет наличие `prepared_audio_local_path` или `pending_audio_file_id`.
- Нет сохранённого трека → "Не вижу сохраненного трека. Нажми «Отправить трек» и пришли файл."
- Есть → **reuses сохранённые `lyrics_text` и тайминги** из стейта (не переспрашивает), `versions_count=1`, прыгает сразу в `_ask_footage_genre` (или `_ask_vibe_shortlist` если вайб-флоу включён).
- Режим субтитров сбрасывается в дефолт кодом, но пользователь выбирает его заново на обычном шаге.

> **Итого:** REUSE пропускает шаги 4–6 (lyrics / fragment / timing) и идёт сразу к футажу.

### Ошибки

- Файл слишком большой → "Не удалось подготовить аудио: Telegram не дает скачать этот файл (слишком большой). Пришли более легкий файл: mp3/m4a или обрезанный фрагмент."
- Другая ошибка → "Не удалось подготовить аудио. Попробуй ещё раз." + alert в ops-чат.

## 4. WAIT_LYRICS_TEXT — текст песни

Бот ждёт текст обычным сообщением.

```
Трек готов! Пришли текст песни обычным сообщением.
Он нужен для точной синхронизации субтитров с аудио.
```

После получения:
- Сохраняет `lyrics_text`.
- **Тим-бот**: кикает фоновый `_trigger_vibe_ranker_task` — пока юзер проходит fragment/timing/bg, ранкер уже считает бакеты по тексту (нулевая задержка на шаге вайба).
- → `STAGE_WAIT_FRAGMENT_CHOICE`.

```
Текст получил. Хочешь указать конкретные строки, которые должны войти в клип?
[Указать строки из текста]
[На усмотрение ИИ]
```

> **Отличие тим-бота.** В тим-боте сначала спрашивается тайминг, потом текст (`WAIT_LYRICS_CHOICE`). В паблик-боте текст запрашивается обязательно сразу.

## 5. WAIT_FRAGMENT_CHOICE / WAIT_FRAGMENT_TEXT — конкретный отрывок

Опциональный шаг: уточнить, какие строки войдут в клип (например, припев).

- [На усмотрение ИИ] → `_ask_timing_choice`.
- [Указать строки из текста] → `STAGE_WAIT_FRAGMENT_TEXT`.

```
Скопируй и пришли нужные строки прямо из текста песни — те слова,
которые хочешь видеть в клипе. Например — припев трека.
```

Фрагмент получен → `STAGE_WAIT_CONFIRM_TEXT`:

```
Подтвердить текст?

Текст песни:
<первые 200 символов>...

Строки из текста:
<фрагмент>
[Да]
[Вернуться назад]
```

- [Да] → `_ask_timing_choice`.
- [Вернуться назад] → сброс, назад в `WAIT_LYRICS_TEXT`.

## 6. WAIT_TIMING_CHOICE / WAIT_TIMING_INPUT — тайминг

```
Хочешь указать конкретный тайминг трека для клипа?
Например: 1:20-1:50 или 80-110 (в секундах).
Максимальный тайминг: 15с.

Это строгое ограничение, если ты поставишь больше,
то задача вернется с ошибкой и придется заполнять все заново.
[Указать тайминг]
[На усмотрение ИИ]
```

- [На усмотрение ИИ] → `_ask_bg_mode`.
- [Указать тайминг] → `STAGE_WAIT_TIMING_INPUT`:

```
Отправь тайминг в формате: 1:20-1:50 или 80-110
```

Валидация: мин. 5 сек, макс. 22 сек.

```
Тайминг установлен: 1:20 - 1:50 (30 сек).
```

→ `_ask_bg_mode`. Также запускает фоновый анализ дропа (`_trigger_hook_analysis_task`) если указан фрагмент.

## 8. WAIT_FOOTAGE_GENRE / WAIT_FOOTAGE_ARTIST — жанр и артист

*Актуально для паблик-бота с `FOOTAGE_VIBE_FLOW_ENABLED=0`. При включённом вайб-флоу этот шаг заменяется вайб-пикером (см. раздел 8b).*

### Жанры (из `config/styles/artist_presets.json`)

- **Хип-хоп** — 6 артистов
- **Поп** — 5 артистов
- **Рок** — 5 артистов
- **Альтернатива** — 4+ артиста

### Выбор жанра

```
Выбери жанр исходников:
[Хип-хоп]
[Поп]
[Рок]
[Альтернатива]
[Назад]
```

[Назад] → `_ask_bg_mode`.

Жанр выбран → `STAGE_WAIT_FOOTAGE_ARTIST` + бот отправляет превью-видео для каждого артиста.

**Приоритет источника превью (паблик-бот):**
`preview_file_id_public` → `preview_file_id` → `preview_s3_url` → URL через `_resolve_preview_source_file_url` → текстовый фолбек.

**Тим-бот:** `preview_file_id` → `preview_s3_url` (без public file_id).

```

[Артист 1]
[Артист 2]
...
[Назад]
```

+ видео-превью с подписью "Артист 1: описание стиля".

### Выбор артиста

- [Назад] → `_ask_footage_genre`.
- Артист выбран → `footage_artist_id = artist["key"]` → `_ask_subtitles_mode`.

## 8b. WAIT_VIBE — вайб-пикер ⚠️ (тим-бот / для портирования)

*Заменяет шаг 8 когда `FOOTAGE_VIBE_FLOW_ENABLED=1`. В паблик-боте стейдж и state-поля зеркалятся для схемной паритетности, но хендлеры не портированы.*

### Механика

- Фоновый ранкер (`_trigger_vibe_ranker_task`) вызывается сразу после получения текста песни (шаг 4).
- Ранкер дёргает orchestrator `/footage/rank-buckets` (LLM по тексту + мудборд).
- Результат — топ-N бакетов = `(theme, tags_group)` — сохраняется в `vibe_ranked_ids` / `vibe_labels_by_id`.
- К моменту, когда пользователь доходит до шага «Футажи», список уже готов (нулевая задержка).

### Интерфейс

```
Готовлю шортлист вайбов…   ← reply keyboard убирается

Выбери вайб(ы) для футажа — можно несколько (тап = ✓ в набор).
Страница 1/3. Выбрано: 0.
«🔄 Обновить» — листать варианты (выбор сохраняется).
«▶️ Готово» — продолжить. «✨ По треку (авто)» — топ-1 по треку.

[▫️ Тревожная природа]         ← inline-кнопки (тап = toggle ✅)
[▫️ Ночной город]
[▫️ Тёмный глитч]
[▫️ Уличная сцена]
[▫️ Холодный портрет]
[🔄 Обновить] [▶️ Готово]
[✨ По треку (авто)]
```

- Тап по вайбу → toggle `✅`/`▫️`, счётчик обновляется.
- [🔄 Обновить] → следующая страница (выбор сохраняется).
- [✨ По треку (авто)] → выбирает топ-1 бакет автоматически.
- [▶️ Готово] → если ничего не выбрано → "Выбери хотя бы один вайб или нажми «По треку (авто)»."

После подтверждения:

```
Вайбы: Тревожная природа, Ночной город
```

→ `_ask_subtitles_mode`. `footage_artist_id` сбрасывается (вайб-флоу использует тег-матчинг, без артиста).

**Фолбек:** если ранкер вернул пустой список → "Не удалось подобрать вайбы по треку — выбери стиль вручную." → уходит в обычный жанр/артист пикер.

## 10. Хук-флоу — HOOK_FLOW_ENABLED=1

*Порт из тим-бота. Хендлеры присутствуют в паблик-коде начиная с pull `c9af8ba`.*

### WAIT_HOOK_CHOICE

```
Сделать хук в ролик? Хук — это короткий FX-акцент на дропе, помогает удерживать зрителя.

Звуковой дроп найден на ~1:23 (уверенность 87%).   ← если анализ готов
[Сделать хук]
[Без хука]
```

- [Без хука] → `_proceed_to_versions_or_confirm`.
- [Сделать хук] → `WAIT_HOOK_DROP`.

### WAIT_HOOK_DROP — момент дропа

```
Выбери момент дропа. 🎯 — лучший кандидат.
ℹ️ Хук: ~3–4с разгон ДО + 10–12с кора ПОСЛЕ дропа.

[🎯 1:23 (87%)]
[1:21 (72%)]
[1:25 (60%)]
[В отрывке нет дропа]
[Ввести вручную]
[Назад]
```

- [Назад] → `_ask_hook_choice`.
- [В отрывке нет дропа] → `hook_drop_t=None` → `_ask_hook_type`.
- [Ввести вручную] → `WAIT_HOOK_DROP_MANUAL`: "Отправь момент дропа в формате 1:23 или 83 (секунды)."
- Выбор кандидата → валидация (дроп внутри фрагмента) → "Дроп зафиксирован на 1:23." → `_ask_hook_type`.

### WAIT_HOOK_TYPE — категория хука

```
Выбери тип хука:
• «Мысль» — голосовая TTS-вставка в первые секунды.
• «Движение» — морфинг руки/головы в такт, вспышка на дропе.
• «Эффект» — хук + переход + грейд (3 шага).
• «Объект» — фигура-переход на склейках до дропа, молния на дропе, рандомный визуал-переход после.
• Звук — скоро добавим.

[Звук] [Объект]
[Эффект] [Движение]
[Мысль]
[Назад]
```

[Назад] → `_ask_hook_drop`. F1/F2/F3/F4 требуют `hook_drop_t` (без дропа → возврат на дроп-шаг).

### F3 «Эффект» — 3 шага

**Шаг 1/3 — хук на дропе:**
```

• Молния — вспышка-молнии + шейк.
• Затвор — нарезка затвора + лого-штамп.
• Слоу-шаттер — echo-шлейф + вспышка (можно растянуть).
[Молния] [Затвор] [Слоу-шаттер] [Пропустить] [Назад]
```

**Шаг 2/3 — переход на склейках:**
```
[Снап-вайп] [Минимакс] [Инверт] [Экстракт] [Вспышки] [Тряска]
[Пропустить] [Назад]
```

**Шаг 3/3 — стилизация (грейд до дропа):**
```
[Ксерокс] [Аналог-глитч] [Неон] [Старая камера] [Пиксель-зерно] [Тепловая карта]
[Пропустить] [Назад]
```

Если «Слоу-шаттер» → дополнительный шаг:
```
[Стандарт] [До конца ролика] [3 футажа после] [Назад]
```

→ `_proceed_to_versions_or_confirm`.

```
Готово — лови первый ролик! Скажи, пожалуйста, как оцениваешь по 10-балльной шкале?

Остаток генераций: N
[До 5] [5-6] [7-8] [9-10]
```

### Ветки

**[До 5] → STAGE_FEEDBACK_LOW**
```
Приняли, готовы услышать обратную связь и вместе с ней исправить ролики — бесплатно.
Давай, ты пройдешь 5 вопросов в форме (там меньше минуты)...
Учтем твою обратку и пришлем 2 ролика с исправлениями, так, чтобы тебе вкатило. Сделаем?
[Делаем!]
```
[Делаем!] → ссылка на форму → `STAGE_IDLE`.

**[5-6] → STAGE_IMPROVEMENT_FEEDBACK**
```
Спасибо за честность! Что бы ты поменял в первую очередь?
[Субтитры] [Исходники] [Переходы] [Другое]   ← inline
```
→ логирование → "Записал! ... у тебя ещё N бесплатных генераций" → `STAGE_IDLE`.

**[7-8] / [9-10] → STAGE_SALES_PITCH**
```
Отлично, значит мы попали!

Это один ролик — а представь: каждую неделю у тебя появляется свежий контент
под твои треки, в твоём стиле и вайбе. Без съёмок и монтажа...
[Хочу так]
```
→ воронка пакетов (Trial 990₽ / Blast 1990₽/мес / Glow 7990₽ / Impulse 29990₽) → TBank-оплата.

## 16. Ротация футажей

- Redis: `rotation_cursor` + `rotation_history` per `(chat_id, artist_id)`, TTL 30 дней.
- Курсор сдвигается после каждого успешного job'а.
- При вайб-флоу `artist_id` сбрасывается → ротация работает иначе (по `(chat_id, bucket_id)`).

## 17. Команды бота

| Команда | Действие |
|---------|---------|
| `/start` | Онбординг / вернуться в начало |
| `/sendtrack` | Отправить трек (= `_move_to_wait_audio`) |
| `/packets`, `/packages` | Показать все тарифы |
| `/cancelsubscription` | Отменить подписку |
