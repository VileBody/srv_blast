## Как проверять локально

Запуск — `.claude/launch.json`: `blast-backend` (порт 8001, mock) + `blast-frontend` (порт 5173). Вход через `POST /api/dev/login`, TikTok-мок — `/api/tiktok/auth`.

Перед каждым коммитом (в `web_app/frontend`):

```bash
npx tsc --noEmit
npm run ui:check
npm run i18n:check
npm run build
```

**Если новые токены в dev-сервере не применяются, это старый конфиг Tailwind.** Tailwind читает `tailwind.config.js` раньше `.ts`. Этот `.js` (и `.d.ts`) генерирует `tsc -b` внутри `npm run build`, в гите его нет (он в `.gitignore`), и после правки `.ts` он остаётся старым. Нужно удалить `tailwind.config.js` и `tailwind.config.d.ts` (или запустить `npm run build`) и перезапустить vite. В CI и на проде проблемы нет.

Скриншоты «до / после» в облачной сессии делались Playwright-скриптами из её временной папки (все страницы и 5 шагов визарда на 1440 и 390). В репо этих скриптов нет, при локальной проверке их нужно написать заново. Две ловушки:

- headless Chromium не играет H.264 — mp4 подменять на WebM;
- мок-бэкенд не достаёт до своего S3 — запросы к медиа роутить на локальный клип.
