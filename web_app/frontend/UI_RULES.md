# Единые правила UI Blast

Правила общие для всего веба: визард, проекты, статистика, профиль, тарифы, вход, промо-блоки.
Наглядная сводка «сейчас и как должно быть» лежит в артефакте «Единые правила UI»; этот файл — рабочая выжимка для кода.

Новый код пишется только на токенах ниже. Старые значения — долг: `npm run ui:check` не даёт его наращивать (см. «Проверка»).

## Шкалы

### Кегль и высота строки

| Токен | Кегль / строка | Где |
|---|---|---|
| `text-ui-32` | 32 / 40 | заголовок страницы, крупные цифры промо |
| `text-ui-24` | 24 / 32 | заголовок карточки и секции |
| `text-ui-20` | 20 / 28 | крупные кнопки, подзаголовки |
| `text-ui-16` | 16 / 24 | основной текст, обычные кнопки |
| `text-ui-14` | 14 / 20 | вторичный текст, мета, пилюли |
| `text-ui-12` | 12 / 16 | подписи, метки, счётчики |

- Вес два: 350 для текста, 400 для заголовков и кнопок.
- Не `leading-none`: высота строки идёт вместе с кеглем, иначе режутся выносные элементы.
- В заголовках без двоеточий.

### Радиусы

`rounded-r6` метки, превью в строке, чекбокс · `rounded-r10` контролы до 44 px · `rounded-r15` панели внутри карточки, кнопки 60 px · `rounded-r25` карточки страницы, модалки · `rounded-full` пилюли, тумблер, аватар.

Внутренний элемент скруглён меньше внешнего на величину отступа между ними. `r9`, `r12`, `r20`, `r40` — наследие.

### Высоты контролов

`h-ctl-xs` 24 метка · `h-ctl-sm` 32 малый (пилюли, пейджер, малые кнопки) · `h-ctl` 44 обычный (поля, кнопки, табы) · `h-ctl-touch` 52 крупный на телефоне · `h-ctl-lg` 60 главное действие шага.

Всё в одном ряду одной высоты. Иконка-кнопка квадратная и той же высоты, что соседняя кнопка.

### Цвета

Поверхности: `bg` → `card` (карточка страницы) → `panel` (панель внутри карточки) → `field` / `field-hover` (поля, вторичные кнопки).
Акцент: `accent-strong` (главная кнопка, активный таб), `accent-light` (тумблер, фокус), `accent-soft` + `accent-line` (выбранная пилюля, пустое место).
Текст: `text`, `text-80`, `text-60`, `text-40`. Статусы: `success`, `warning`, `error` — только по смыслу.

Цвета в компонентах только из токенов. Градиенты `grad-soft-*` — для промо и обложек, не для контролов.

## Компоненты

Живут в `src/components/ui/kit/` (импорт из `components/ui/kit`). Витрина всех состояний — `/dev/kit` (только dev-сборка): переводимый экран сверяется с ней, а не с соседними страницами.

- **Кнопки**: главная (заливка `accent-strong`, одна на область), вторичная (заливка `field`), текстовая, иконка. Рамок у кнопок нет. Готовность главной кнопки показывает заливка: не готово — `field`, готово — `accent-strong`. Незаполненная форма подсвечивает пропуски по нажатию; настоящий disabled только там, где этого требует внешнее правило.
- **Segmented**: этапы визарда, батчи, итерации, режимы, фильтры — один компонент в двух размерах. «+» — последним сегментом.
- **Pager** «‹ 1 / 2 ›»: тихий, `field`, 32 px; у медиа живёт внутри плеера.
- **SectionHeader**: заголовок 24 слева, мета 14 и малые действия справа, «смотреть всё» текстом со стрелкой.
- **Panel**: card → panel → field. Пунктир только у пустого места, куда можно что-то положить или создать.
- **Tag** (показывает данные, 24 px, r6, без рамки) и **Pill** (выбирается, 32 px, круглая, выбранная с `accent-line`).
- **ActionBar**: одна строка действий на весь сайт — слева контекст, справа главное действие. Все пять шагов визарда, выкладка в TikTok, модалки.
- **Field / Checkbox / Switch**: поле 44 r10, галочка 20 r6, тумблер 40 × 24. Ошибка поля — текстом рядом, не тостом.
- **Dialog**: карточка r25 на `scrim`, заголовок 24 и закрытие в шапке, низ — ActionBar. Esc и клик по подложке закрывают, фокус возвращается туда, откуда открыли; считается в `useModalCount`, как старая `Modal`.
- **Icon**: `src` — ассет из Figma (маска в `currentColor`), `children` — пути `GLYPH` для viewBox 24.

## Иконки

- Высота глифа 0,7 кегля соседнего текста (в em), тяжёлые (заливка или обводка толще 12% высоты) 0,62. Речь о видимом глифе: у путей `GLYPH` поле viewBox, поэтому `Icon` сам растягивает их коробку на 24/15.
- Цвет на ступень тише текста, акцент и белый — только у активного состояния.
- Отступ до подписи 0,4–0,45 кегля; у двухстрочной подписи иконка по первой строке.
- Только у разделов и действий, у подзаголовков нет.

## Проверка

`npm run ui:check` (запускается в CI) считает пять правил: `font-size`, `radius`, `height`, `color`, `nudge` (ручные подгонки текста на 1–3 px). Текущий долг записан в `scripts/ui-debt.json` по файлам.

- Нарушений в файле стало больше, чем в долге, — проверка падает и показывает строки.
- Долг уменьшился — зафиксируй: `npm run ui:check -- --update`.
- Сводка: `npm run ui:check -- --report`.
- Осознанное исключение (иллюстрации гайдов, превью эффектов, пиксельная геометрия): комментарий `ui-allow` на строке или строкой выше.
