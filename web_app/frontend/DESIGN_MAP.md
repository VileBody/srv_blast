# Blast Wizard — карта дизайна (источник: Figma, файл «Blast», Wireframe 7–35)

Все значения сняты с макетов через Figma MCP. Правило: **не выдумывать размеры** —
всё, что рендерится, обязано соответствовать этой карте либо конкретному узлу макета.
Масштабирование: макет построен на вьюпорт 1440×1024; при меньшей ширине компоненты
скейлятся классами `max-xl:` (типографика 24→17/18, чипы 60→48), геометрия сохраняет пропорции.

## Типографика (шрифт Point; fallback системный до загрузки TTF)

## Ключевые размеры
- Сайдбар: рейл 188px; лого 60×60 @ (64,65); иконки 40px зона, аватар 68 с кольцом 2px.
- Карточки этапа: шапка 700×240; пикер 700×640; правая колонка 472 (верх 659, низ 226).
- Внутренний паддинг карточек: 40px (в коде px-space-6/7 + px-[40px] для панелей).
- Таб-бар этапов: 620×60, активный пил 124×60, border-2 #8b6fe6, r15.
- Панель пикинга: 620×382, r15, grad-soft-10; заголовок (40,40); лента карточек y=89, h=253.
- Карточки: футажи 142×253, фото/стили 338×253, gap 20; выделение: inset 3px #5f42b9 (футажи) / 2px #8b6fe6 (фото), поверх медиа отдельным слоем.
- Чипы (склейки/стили/типы): h=60, r15, grad-soft-20, иконка 40×40 + текст 24 Book; выбранный — inset 2px #8b6fe6, текст белый; disabled — opacity .4.
- Строки типов хука: 620×80, r15, gap 20, вертикальный скролл под фейды 28px (#140e24→прозр.).
- Тайминг дропа: панель 620×60; чипы во всю высоту (актив — пил ~98×60 border-2 accent).
- Пилюли пула: h=60, r15; счётчик-квадрат 60×60 border-2 accent слева; текст 24 Book. Все пилюли фона — «Хn Лейбл».
- Мини-пилы Пула: h=25, r5, текст 14, иконбокс 25×25 r5 border 1px accent, иконки белые ~13px.
- «Всего видео» (Пул): 620×80, border-2 accent, r15, закреплён, текст 32.
- Фейды лент: 31px, цвет #201837 (в панелях) / #140e24 (на карточках), только поверх контента, поверх — pointer-events: none.
- Кнопки футера: назад 60×60 r15; «Продолжить» — оставшаяся ширина, стрелка 25×15; подсветка (inset 1.5px accent) ТОЛЬКО при валидном выборе.
- «Добавить …» (пустой футер): пил 310×60, текст 24 по центру.
- Тумблер: 60×30, кноб 24, включён — фон #8b6fe6.

## Цвета/градиенты
- Карточки: #140E24 (r25). Подложки панелей: grad-soft-10 (139,111,230→95,66,185 @ 10%).
- Активные элементы: grad-soft-20 + border 2px #8b6fe6.
- Дэш-обводки: SVG-паттерн stroke-dasharray 24 24; белая rgba(246,245,253,.8) поверх контента превью, фиолетовая #8B6FE6 у дроп-зон.
- Иконки: единый набор из Figma (`public/assets/figma/*`), перекраска только через CSS-mask + currentColor. Активная — #8b6fe6, неактивная — rgba(246,245,253,.8), в мини-пилах Пула — белые.

## Механики (зафиксированные UX-решения)
- Пилюли футера = живое отражение настроенных разделов; «+» — переход к следующему разделу, не подтверждение. Клик по пилюле — редактирование раздела.
- Порядок этапов: Трек → Фон → Текст → Хук → Пул.
- Валидация таймингов: mm:ss:ms, автоформат двоеточий, значения не могут превышать длительность трека.
- Пул: изменение «Всего видео» не трогает ручное распределение — считается «нераспределено ±N»; «Распределить поровну» — явная кнопка.
